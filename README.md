# 剧情创作工作台

用于编写连续剧情、配置文字演出、场景与声音的 Windows 桌面工具。当前源码版本 0.3.13。

## 运行发行版

解压 Windows x64 便携 ZIP，运行 剧情创作工作台.exe。工程与恢复历史保存在程序同级的“验收数据”目录；升级前备份自己的数据，发行包不包含任何用户工程。

## 开发

使用支持 TypeScript 类型剥离的 Node.js 24：

```sh
npm ci
npm run dev
npm test
npm run typecheck
npm run build
```

依赖安装需要访问 npm；Electron 安装需要下载运行时。版本以 package-lock.json 为准。npm run dist:installer 可构建 Windows 安装包；本次发行提供便携 ZIP。

## 当前功能与限制

支持章节与组目录、本地工程库、工程导入导出、文字动效、图片、声音、保存与恢复历史。本次发布检查：177 项测试通过，类型检查与构建通过；未重做完整桌面交互验收。长时间切章的性能、关键词反色长文本性能和右键菜单关闭问题仍待处理。
